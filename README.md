# مطعم وكافتيريا ليالي الحلمية - Layali El Helmeya Website

موقع إلكتروني متكامل لمطعم ليالي الحلمية (رأس الخيمة) يدعم اللغتين العربية والإنجليزية، البحث الفوري، السلة الفاعلة، والطلب المباشر عبر الواتساب.

## 🛠️ كيفية تشغيل الموقع وتعديل البيانات

### 1. وضع الصور واللوجو:
- ضعي صورة اللوجو في المجلد images/logo.jpg.
- يمكنك إضافة صور الأطباق داخل مجلد images/ وتعديل مسار الصورة في ملف js/menu.js.

### 2. إضافة رقم الواتساب الخاص بالمطعم:
- افتحي ملف js/script.js.
- ابحثي عن المتغير RESTAURANT_WHATSAPP واكتبي الرقم بالصيغة الدولية بدون (+) مثل: "971500000000".

### 3. تعديل الأسعار والأصناف:
- افتحي ملف js/menu.js.
- ستجدين مصفوفة menuData التي تحتوي على جميع الأصناف المأخوذة من المنيو المرفق. يمكنك إضافة أو تعديل الأسعار، الأوصاف، والأسماء بكل سهولة.

### 4. تعديل العروض:
- في ملف js/menu.js يمكنك تعديل مصفوفة offersData.

### 5. كود الـ QR Code:
- قومي بربط كود الـ QR مباشرة برابط صفحة menu.html الخاصة بالموقع فور رفعه على الاستضافة المجانية مثل GitHub Pages أو Cloudflare Pages.
